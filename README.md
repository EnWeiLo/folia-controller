# 流詞 Flowrics（Android ＋ Windows）

<img src="branding/flowrics-icon-512.png" width="96" alt="流詞 logo">

把 [Folia](https://github.com/chthollyphile/folia-major) 的全螢幕動態歌詞放到手機、平板或電腦上，**本身不播放音樂**。
你照常用 Spotify、YouTube Music 或任何播放器聽歌，這個 App 會：

- 讀取正在播放的歌曲、封面和進度（透過 Android 的媒體工作階段）
- 自動找同步歌詞（見下方「歌詞來源」），盡量用逐字歌詞，並附翻譯和羅馬拼音
- 用 Folia 的歌詞動畫全螢幕顯示，跟著播放器同步
- 底部的資訊卡顯示封面、歌名、歌手和專輯，卡片顏色跟著封面變；上一首、播放／暫停、下一首、拖曳進度條
- Android 可以用手勢操作，Windows 另有桌面歌詞
- 除了 Folia 的動畫，還有流詞自己的 21 種特效（見「流詞特效」）
- 介面是液態玻璃風格：資訊卡和設定視窗是半透明的玻璃，後面的歌詞動畫會模糊透出來

## 歌詞來源

每首歌會同時搜尋以下來源，依歌名、歌手、長度評分，挑最吻合的版本，並且偏好逐字歌詞：

| 來源 | 特色 |
| --- | --- |
| 本機歌詞資料夾 | 自己放的 `.lrc`／`.ttml` 檔，有對到就優先使用（UTF-8、Big5、GB18030 都能讀） |
| AMLL 歌詞庫 | 社群手工校對的逐字歌詞，品質最好。Android＋Spotify 會直接用 Spotify 歌曲編號查詢 |
| QQ 音樂 | 華語、日文歌多，逐字歌詞＋翻譯＋羅馬拼音 |
| 酷狗音樂 | 覆蓋廣，逐字歌詞，常附翻譯與羅馬拼音 |
| LRCLIB | 開放歌詞庫，英文歌多，逐行時間 |
| 網易雲音樂 | 對中國以外地區（含台灣）只回傳加密的搜尋結果，目前在台灣用不到 |

- **羅馬拼音歌名**（例如 Spotify 顯示 "Yoru ni Kakeru"）：改用「歌手＋長度完全吻合」比對。
- **Live／Remix／伴奏**等其他版本會排在原版之後，除非你播的就是那個版本。
- **簡體轉繁體**：所有來源都會轉，日文原文和羅馬拼音不會被改動。
- **換歌詞**：控制列的歌詞按鈕（電腦版也可按 L 或點狀態列的「歌詞：…」）列出所有來源的候選，選了會記住，下次播同一首自動使用；也能設定某首歌不顯示歌詞。
- **副歌詞**（歌詞下面那一行）：中文翻譯、羅馬拼音、兩者或不顯示，每台裝置各自設定。

## 流詞特效

預設用的是 Folia 的動畫；另外還有一組自己寫的歌詞特效（`shared/web/fx.html`，Android 和 Windows 共用）。設定的「歌詞動畫」裡依序分成三組：

- **Folia 動畫**：Folia 原本的 14 種（預設「流光」）。
- **流詞特效**：潛入（字一個個從深處浮上來，每句換一種排版）、極簡（滾動歌詞）、卡拉OK（雙行 KTV、前奏倒數）、電影字幕（寬銀幕黑邊）、墨染（宣紙暈墨、中文直書）、液面（水面倒影與漣漪）、星塵、霓虹、黑膠（封面當唱片標籤）、漫畫對白（對話框＋狀聲詞）、終端（綠色終端機打字）、彈幕（還有觀眾一起刷）、LED 看板（點陣跑馬燈）。
- **誇張特效**：爆破（字砸下來畫面震動、換句整句炸開）、隕石、故障（亂碼解碼、RGB 分離）、漩渦（黑洞）、煙火（火花聚成字）、果凍、曲速（每句一次曲速跳躍）、碎玻璃。

「墨染」有自己的特效選項（Android：設定 →「特效選項」；Windows：設定面板）：排版可選「翻頁」（由右往左寫，寫滿一頁就翻頁）或「捲軸」（由右往左寫，舊的字往右滑走）；配色有宣紙、夜金（暗色底金色珠光字）、封面（專輯封面模糊當背景）、青瓷、靛夜。

特效會用封面配色、跟著逐字時間軸走，開了「跟著音樂律動」時重拍會帶動震動、光暈、漣漪等效果；副歌詞設定一樣有效。「動畫與外觀細節」面板只對 Folia 動畫有用。

## 動畫與外觀

設定裡的「動畫與外觀細節」打開一個面板，Folia 原本設定裡能調的東西都在這裡（Android 和 Windows 共用同一個面板）：

- **動畫細節**：14 種歌詞動畫各自的細部設定。例如「商籟」的外層邊框（右上角的氣氛短句、左下角的主題名稱就在這裡關）、巨型裝飾字、背景裝飾、鏡頭運動；「莫奈」的歌曲描述標籤等。
- **文字**：字型、自訂字型名稱、字級、粗細、整體透明度。
- **副歌詞區**：隱藏「下一句預告」（沒有翻譯時 Folia 在下方預告的下一句）、字幕背景、模糊、字幕字型與大小、和聲字幕。
- **背景**：背景類型（隱現、通用、莫奈、漫遊、空）與各自的細節。

改了之後按「套用」，畫面會重新載入。每台裝置各自記住，每一頁都可以「恢復預設」。標示「需要聲音資料」的選項目前沒有效果（Folia 在這裡收不到聲音）。

選項清單是用 `tools/gen-tuning-schema.py` 從 Folia 原始碼整理出來的（`tools/folia-schema.json`），Folia 更新後可以重新產生。

## Windows 版

下載 Releases 裡的 `Flowrics-<編號>.exe`（以前叫 `FoliaController-<編號>.exe`；新版開啟時會自動關掉舊版，設定沿用，舊檔可以刪掉），直接執行，不用安裝。第一次執行如果出現 SmartScreen，按「其他資訊 → 仍要執行」。

- **打開就是 Folia 視窗**：讀取 Windows 的媒體播放資訊（音量面板裡那個），支援 Spotify 桌面版、Chrome／Edge 裡的 YouTube Music，以及大部分播放器。
- **資訊卡**一直顯示，點一下歌詞畫面收起，再點一下打開。快捷鍵：空白鍵播放／暫停、← → 倒轉／快轉 5 秒、N／P 下一首／上一首、L 換歌詞、D 桌面歌詞、F、F11 或雙擊切換全螢幕、Esc 離開。
- **桌面歌詞**：系統匣選單或資訊卡上的螢幕按鈕打開。透明、永遠在最上層，兩行：歌詞（唱到的字會換成封面的顏色）和小字翻譯，字有描邊，放在白色網頁或深色桌布上都看得清楚。滑鼠移到歌詞上會出現工具列（切歌、播放暫停、字放大縮小、鎖定、關閉），按住歌詞可以拖到任何位置。鎖定後滑鼠會直接穿過，要解鎖請到系統匣選單取消「鎖定桌面歌詞」。全螢幕玩遊戲、看影片或簡報時會自動隱藏。
- **關掉視窗**會退到系統匣繼續執行，點系統匣圖示就能再打開。右鍵選單有：在瀏覽器開啟、桌面歌詞、鎖定桌面歌詞、允許區網裝置連線、複製區網網址、本機歌詞資料夾、開機時自動啟動、結束。
- **給平板用**：勾選「允許區網裝置連線」後，同一個 Wi‑Fi 下的平板或手機用瀏覽器打開選單裡的網址（例如 `http://192.168.1.23:39863/`），就能顯示電腦正在播的歌詞，也能遙控。Windows 跳出防火牆詢問時，請允許「私人網路」。
- **設定**（資訊卡右邊的齒輪）：歌詞動畫、畫質、副歌詞、日間主題、顯示 FPS 是每台裝置各自設定；簡轉繁、時間偏移是所有裝置共用。
- 視窗用的是 Windows 內建的 Edge 引擎（WebView2），Windows 10／11 都已內建。設定和紀錄存在 `%LOCALAPPDATA%\FoliaController`。

## 建置（不需要 Android Studio 或 Visual Studio）

1. 在 GitHub 建一個新的 repo（可以設為 Private），把這個資料夾的內容全部上傳。
2. 上傳後，GitHub Actions 會自動執行 **Build**，約 10–15 分鐘：先打包 Folia 網頁，再同時建置 APK 和 Windows exe。Windows 版還會在雲端實際啟動，用模擬播放器檢查網頁、WebSocket 和播放控制，並截圖（在該次執行的 `windows-screenshots` 附件裡）。
3. 完成後到 repo 的 **Releases**，下載 `.apk` 或 `.exe`。

之後只要修改並推送程式碼，就會產生新版。每一版都用同一把簽章，可以直接覆蓋安裝。
想換成最新版的 Folia，可以到 **Actions → Build → Run workflow**，把 `folia_ref` 填成 `main`。

## 第一次使用

1. 安裝 APK（需要允許「安裝不明來源的應用程式」）。
2. 打開 App，按「開啟通知使用權設定」，把 **流詞** 打開。
   - Android 13 以上自行安裝的 App，這個開關可能是灰色的，並顯示「受限制的設定」。這時先按「開啟 App 資訊」，點右上角 **⋮** → **允許受限制的設定**，再回去開啟通知使用權。
   - 小米 HyperOS 的位置是：設定 → 應用程式 → 權限 → 特殊應用程式存取權 → 通知使用權。
3. 在 Spotify 或 YouTube Music 播一首歌，回到流詞即可看到歌詞。

這個 App 只用通知使用權來讀取媒體工作階段，不會讀取或保存任何通知內容。

## 操作

- **手勢**（第一次開啟會有教學，之後在設定 →「手勢說明」可以再看）：
  - 點一下：收起／打開資訊卡（不會自動收起）
  - 點兩下：播放／暫停
  - 往左滑：下一首；往右滑：上一首
  - 往上滑：打開設定
  - 長按：換歌詞
- **點封面**：切回正在播放的 App
- **資訊卡右側的調整按鈕**（或往上滑）：設定
  - 歌詞動畫：流光、心象、雲階、浮名、莫奈、群唱、傾訴、回環、鏡台、時計、商籟、凝彩、繪光、靜止
  - 畫質：高畫質（原生解析度）、均衡（約 75%，預設）、流暢（約 60%，並關閉幾何背景）。解析度越低越順，直式手機上的歌詞也會顯得稍大
  - 刷新率：自動（螢幕最高）或指定 120／90／60 Hz。系統或廠商（例如 HyperOS）可能仍會限制，若沒有生效，到系統「顯示」把更新率調到最高或自訂
  - 顯示 FPS：左上角顯示 Folia 實際每秒畫出的幀數、最慢一幀的時間和目前螢幕刷新率
  - 副歌詞（翻譯／羅馬拼音／兩者／不顯示）、日間主題、簡體歌詞轉繁體
  - 本機歌詞資料夾：選一個放 `.lrc` 的資料夾
  - 歌詞時間偏移：戴藍牙耳機時如果歌詞偏早，可以調成 +250 到 +500 ms
  - 保持螢幕常亮

## 運作原理

```
Spotify / YouTube Music ──媒體工作階段──▶ MediaHub（Kotlin）
                                            │ 找歌詞：網易雲 / LRCLIB
                                            ▼
                          WebView 裡的 Folia「Now Playing」頁面
              （folia-bridge.js 把原本的 WebSocket 換成和 App 之間的直接通道）
```

Folia 原本就有一個給 OBS 用的「Now Playing」模式，它只顯示歌詞、不播放音樂，靠 `ws://localhost:9863` 接收
`Track`、`Lyric`、`PlayerPauseState`、`PlayerProgress` 四種事件。這個 App 在 WebView 裡送出相同的事件，
所以 **Folia 的程式碼完全沒有修改**。CI 每次會抓 Folia 原始碼、用 `vite build` 打包，再放進 APK。

| 檔案 | 用途 |
| --- | --- |
| `MediaHub.kt` | 追蹤目前播放的 App、讀取歌曲資訊和進度、送事件給 Folia、處理播放控制 |
| `LyricRepository.kt` | 各來源的搜尋、評分與下載（QQ、酷狗、AMLL、LRCLIB、網易雲） |
| `LyricFormats.kt` | 各種歌詞格式（YRC、QRC、KRC、TTML、LRC）的解析與解密，轉成 Folia 的歌詞容器 |
| `LocalLyrics.kt`、`LyricChoices.kt` | 本機歌詞資料夾；記住手動選的歌詞 |
| `FoliaAssetServer.kt` | 在 `https://appassets.androidplatform.net/` 提供 Folia 網頁，並注入橋接腳本和 viewport 設定 |
| `MainActivity.kt` | 全螢幕 WebView、控制列、權限說明畫面、設定 |
| `assets/folia-bridge.js` | 把 Folia 的 Now Playing WebSocket 換成原生橋接 |

Windows 版（`windows/FoliaController.Windows`，C# / .NET 8）不需要橋接：小程式本身就是一個本機網頁伺服器，直接提供 Folia 要連的 `/api/ws/lyric` WebSocket。

| 檔案 | 用途 |
| --- | --- |
| `MediaSources.cs` | 讀取 Windows 媒體工作階段（SMTC）：歌曲、封面、進度與播放控制 |
| `MediaHub.cs` | 找歌詞、產生 Folia 的事件、時間校正（和 Android 版相同規則） |
| `LyricRepository.cs`、`LyricFormats.cs` | 與 Android 版相同規則的歌詞搜尋與格式轉換；繁簡轉換用 Windows 內建功能 |
| `LocalLyrics.cs`、`LyricChoices.cs` | 本機歌詞資料夾；記住手動選的歌詞 |
| `WebServer.cs` | 小型 HTTP ＋ WebSocket 伺服器；只接受 IP 或 localhost，擋下其他網站的請求 |
| `MainForm.cs` | WebView2 視窗、全螢幕、依螢幕縮放調整清晰度 |
| `TrayContext.cs` | 系統匣圖示與選單、區網開關、開機啟動 |
| `web/overlay.js`、`overlay.css` | 疊在 Folia 上的控制列與設定面板（電腦視窗和平板瀏覽器共用） |

### 測試

`tests/lyrics/` 放了各種格式的歌詞樣本和預期輸出。Android 版（Kotlin）和電腦版（C#）的格式轉換各寫了一份，CI 會確認兩邊輸出逐位元組相同，也會實際查詢各歌詞來源。測試報告和截圖放在 `ci-reports` 分支。
